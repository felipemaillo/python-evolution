# 🇺🇸 English Version

## Python Learning Journey: Logic & Syntax Evolution

Welcome to my Python study repository! This project serves as a comprehensive log of my progress in Python development, ranging from basic syntax to more complex logic and data structures.

### 🚀 About the Project
This repository contains a collection of exercises (currently over 100) developed during my studies. It demonstrates my evolution as a developer, showcasing how I approach problem-solving and implement Pythonic solutions.

### 🛠️ Project Structure
The project is organized into modular folders to demonstrate clean code practices and logical categorization:

* **01_fundamentals**: Basic operations, input/output, and arithmetic.
* **02_modules_and_libraries**: Integration with libraries like `math`, `random`, `datetime`, and `pygame`.
* **03_text_manipulation**: String analysis and advanced manipulation methods.
* **04_control_structures**: Conditional logic and decision-making (`if/elif/else`).
* **05_loops**: Iteration structures and efficient repetition loops (`for`, `while`).
* **06_composite_structures**: Complex data handling using Lists, Tuples, and Dictionaries.
* **07_functions_and_modularization**: Modular code with functions, parameter handling, and error treatment (`try/except`).

### 📈 Evolution
This is a "living" repository. I am constantly updating it with new exercises and refactoring old ones to apply cleaner code practices and more advanced techniques as I continue my educational journey.
