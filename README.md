# 🇺🇸 English Version

## Python Learning Journey: Logic & Syntax Evolution

Welcome to my Python study repository! This project serves as a comprehensive log of my progress in Python development, ranging from basic syntax to more complex logic and data structures.

### 🚀 About the Project

This repository contains a collection of exercises (currently over 100) developed during my studies. It demonstrates my evolution as a developer, showcasing how I approach problem-solving and implement Pythonic solutions.

### 🛠️ Project Structure

The project is organized into modular folders to demonstrate clean code practices and logical categorization:

- **01_fundamentals**: Basic operations, input/output, and arithmetic.
- **02_modules_and_libraries**: Integration with libraries like `math`, `random`, `datetime`, and `pygame`.
- **03_text_manipulation**: String analysis and advanced manipulation methods.
- **04_control_structures**: Conditional logic and decision-making (`if/elif/else`).
- **05_loops**: Iteration structures and efficient repetition loops (`for`, `while`).
- **06_composite_structures**: Complex data handling using Lists, Tuples, and Dictionaries.
- **07_functions_and_modularization**: Modular code with functions, parameter handling, and error treatment (`try/except`).
- **08_others**: Miscellaneous exercises that don't fit into a single category, including HTTP requests with the `requests` library and reading/writing text files.
- **09_OOP**: Object-Oriented Programming exercises covering classes, inheritance, encapsulation, properties, and abstract classes, applied to varied scenarios such as bank accounts, RPG characters, coffee makers, polygons, and payroll systems.

### 📈 Evolution

This is a "living" repository. I am constantly updating it with new exercises and refactoring old ones to apply cleaner code practices and more advanced techniques as I continue my educational journey.

# 🇮🇹 Versione Italiana

## Percorso di Apprendimento Python: Logica e Sintassi

Benvenuti nel mio repository di studio di Python! Questo progetto funge da registro completo dei miei progressi nello sviluppo con Python, spaziando dalla sintassi di base a logiche e strutture dati più complesse.

### 🚀 Sul Progetto

Questo repository contiene una raccolta di esercizi (attualmente più di 100) sviluppati durante i miei studi. Dimostra la mia evoluzione come sviluppatore, mostrando come approccio il problem-solving e implemento soluzioni in Python.

### 🛠️ Struttura del Progetto

Il progetto è organizzato in cartelle modulari per dimostrare pratiche di codice pulito e categorizzazione logica:

- **01_fundamentals**: Operazioni di base, input/output e aritmetica.
- **02_modules_and_libraries**: Integrazione con librerie come `math`, `random`, `datetime` e `pygame`.
- **03_text_manipulation**: Analisi di stringhe e metodi di manipolazione avanzata.
- **04_control_structures**: Logica condizionale e processo decisionale (`if/elif/else`).
- **05_loops**: Strutture di iterazione e cicli di ripetizione efficienti (`for`, `while`).
- **06_composite_structures**: Gestione di dati complessi utilizzando Liste, Tuple e Dizionari.
- **07_functions_and_modularization**: Codice modulare con funzioni, gestione dei parametri e trattamento degli errori (`try/except`).
- **08_others**: Esercizi vari che non rientrano in una singola categoria, incluse richieste HTTP con la libreria `requests` e lettura/scrittura di file di testo.
- **09_OOP**: Esercizi di Programmazione Orientata agli Oggetti che coprono classi, ereditarietà, incapsulamento, proprietà e classi astratte, applicati a scenari diversi come conti bancari, personaggi RPG, macchine per il caffè, poligoni e sistemi di gestione stipendi.

### 📈 Evoluzione

Questo è un repository "vivo". Lo aggiorno costantemente con nuovi esercizi e rifattorizzo quelli vecchi per applicare pratiche di "clean code" e tecniche più avanzate mentre continuo il mio percorso formativo.
